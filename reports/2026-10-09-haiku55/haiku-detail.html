Methodology

Definitions

Expected implementation cost per valid result is implementation_cost_per_attempt / success_rate; it sets the scatter's cost axis and the Pareto frontier. Table costs include evaluator overhead, which never changes frontier membership. Duration is implementation time plus critical-path evaluator time. Scoring rules, eligibility, dominance, and claim boundaries: see the repository methodology document. Provenance hashes, classifications, source IDs, judge spread, and raw attempts are in the embedded JSON payload.
